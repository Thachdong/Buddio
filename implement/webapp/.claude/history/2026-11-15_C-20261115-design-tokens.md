## Tóm tắt
Hiện tại: theme shadcn mặc định (xám, oklch) → mong muốn: token Buddio do user cung cấp (brand, background, text, border, status, game, chat, radius, shadow). Token đặt nguyên văn trong `:root` của `src/app/globals.css`; biến semantic của shadcn trỏ về token; thêm utility Tailwind cho token mới.

## Quyết định
| Quyết định | Lý do |
|---|---|
| Token gốc nguyên văn trong `:root` ngoài `@layer` | Tailwind vẫn sinh biến theme trùng tên (vd `--color-secondary: var(--secondary)`) trong layer; khai báo ngoài layer luôn thắng → `var(--color-*)` đúng giá trị token (đã đo computed style trong browser) |
| Utility `secondary`/`accent` giữ nghĩa shadcn (nền phụ = `--color-surface-hover`) | component shadcn dùng `bg-secondary`, `hover:bg-accent` cho nút phụ/hover; nếu đổi sang xanh/vàng brand thì mọi component lệch |
| Màu brand trùng tên → `bg-brand-secondary` (#3B82F6), `bg-brand-accent` (#FBBF24) qua `--buddio-secondary/--buddio-accent` | tránh vòng tham chiếu với biến theme cùng tên |
| `--muted-foreground` = `--color-text-secondary` (không phải `text-muted`) | shadcn dùng cho mô tả/phụ đề; #94A3B8 trên #F8FAFC tương phản thấp cho chữ thường |
| `--primary-foreground` = `--color-surface` (#FFF), `--ring` = `--color-secondary`, `--input` = `--color-border-strong`, `--radius` = `--radius-md`, chart-1..5 = game-player-1..4 + accent | token không có giá trị riêng cho các vai trò này |
| `rounded-sm/md/lg/xl`, `shadow-sm/md` lấy thẳng token; `2xl..4xl` = `radius-xl` + 8/16/24px | giữ thang cũ của shadcn ở phần token không định nghĩa |
| Giữ khối `.dark` mặc định shadcn | token chỉ có bản sáng; app chưa bật dark mode |
